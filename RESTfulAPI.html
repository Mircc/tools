配置已启用本地缓存，输入时自动保存。

自定义 Headers

工作原理：启用后，实际请求地址为 代理前缀 + encodeURIComponent(目标URL)，由代理服务器代为请求并补全 CORS 响应头，浏览器即可读取结果。

为什么需要它：CORS 由目标 API 服务器控制，静态页面无法绕过。需在 tools.eu.org 上部署代理服务。

⚠️ 隐私提示：启用代理后，请求 URL、Headers、Body 会经过该代理服务器，请仅使用您自己可控的代理。

支持 HTTPie 1.0.0 格式。
