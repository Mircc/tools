限时密信

互联网时代的“阅后即焚” · 个人隐私保护助手
⚠️ 环境警告： Web Crypto API 需要 HTTPS 安全环境才能运行。
⏱️ 自动销毁时间 (仅加密有效)

在互联网上，任何留言信息都可能被永久保存、检索或恶意收集。如何安全的分享个人信息？

用"限时密信"给信息加上有效期。互动者需在有效期内方可解密。这样创作者既提供了合作机会，又彻底避免了后续的长期骚扰
