URL 编码/解码说明

RFC3986 规定 URL 只允许包含以下字符：

  1. 英文字母（a-zA-Z）
  2. 数字（0-9）
  3. -_.~ 四个特殊字符
  4. 保留字符：! * ' ( ) ; : @ & = + $ , / ? # [ ]

本工具使用 JavaScript 的 decodeURIComponent 解码，encodeURI 与 encodeURIComponent 编码，全部在浏览器本地执行。

encodeURI 不编码：~!@#$&*()=:/,;?+'
encodeURIComponent 不编码：~!*()'
encodeURIComponent 编码范围更大；编码整个 URL 参数值时优先使用它，编码完整 URL 路径时用 encodeURI。
